Kebbi AI 感測互動成果發表

不只是說笑話，更是陪伴精靈

本專案以 Kebbi 機器人為載體，結合 NUWA CODE LAB 簡易模型設計，打造具備高度娛樂性的陪伴機器人。我們的目標是讓獨居長輩與小孩獲得如同家人般的陪伴，成為科技與人類自然互動的橋樑。

專案核心概念

🤖 不只是講笑話機器

我們的專案不是單純讓凱比唸稿，而是將冷笑話包裝成完整的互動遊戲。凱比是一個「會表演、會判斷玩家反應、甚至會嘴砲玩家」的幽默夥伴。

🧠 雙層開發架構

基礎版 (觸摸互動)：穩定優先！玩家透過摸左右手切換難度與開始，摸頭與肚子給予回饋。

進階版 (憋笑挑戰)：導入鏡頭 AI 笑容辨識，若成功偵測玩家笑容，將自動觸發凱比的得意嘲諷模式。

四層系統運作流程

👆

1. 接觸感應輸入

透過實體觸碰凱比的左右手、頭部或肚子，低門檻地啟動遊戲與傳遞回饋。

⚙️

2. 系統狀態判斷

程式邏輯判斷當前難度與遊戲階段，確立有笑/沒笑的功能變數與計分機制。

📝

3. 內容生成

呼叫精選預設題庫或接入 OpenAI API，即時生成冷笑話文本與凱比的反應台詞。

🎭

4. 多模態回饋

整合語音朗讀、動態表情、LED 燈光與搞笑肢體動作，給予玩家最具娛樂性的互動輸出。
