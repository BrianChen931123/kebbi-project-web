給長輩最溫暖的守護精靈

本專案以 Kebbi 機器人為載體，結合 NUWA CODE LAB 模型設計，打造具備「娛樂冷笑話」與「日常健康關懷」的雙核心陪伴系統，讓獨居長輩獲得如同家人般的陪伴，成為科技與人類自然互動的橋樑。

專案四大核心功能

👋

迎賓引導與規則宣導

啟動時，凱比會主動揮手打招呼，並以清晰親切的語音說明互動規則。透過明確告知「摸頭代表肯定、摸肚子代表否定」，大幅降低長輩與機器人互動的學習門檻。

開場設計 語音引導
🎭

冷笑話互動與評分

內建精選冷笑話題庫。講完笑話後，系統會依據長輩的觸摸回饋進行分數加總，給予得意嘲諷（發紅光）或裝傻尷尬（發藍光）的生動反應，顛覆傳統單向說話模式。

冷笑話遊戲 情緒燈光回饋
💖

日常守護與情境問候

捨棄冷冰冰的指令，內建涵蓋「健康關懷、作息追蹤、休閒娛樂」等多元情境的在地化問候語料庫，透過隨機抽取機制，讓長輩每次觸碰都能獲得專屬且不重複的溫馨關心。

零延遲狀態機架構

全面採用「變數開關 (State Machine)」邏輯取代不穩定的語音辨識。實現 0 延遲的觸摸回饋，並結合 8 秒超時防呆機制，避免系統卡死，確保互動體驗極致流暢。
